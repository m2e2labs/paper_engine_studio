Power Query

What Power Query Does in Excel

Excel's tool for bringing data in and tidying it.

Let's say you've heard the name and assumed it was for someone else. Power Query is built into Excel, which also calls it Get & Transform. It brings data in and shapes it, say by removing a column.

Microsoft splits the work into four jobs. Connect to the data. Transform it, while the original stays as it was. Combine data from more than one place. Load the result onto a sheet. It's in Excel for Windows, for Mac and for the web.

Connect, transform, combine, load. That's the whole tool.

Turning a List Into an Excel Table

A query reads a table, and a table grows with your list.

Let's say your sales sit in a plain block of cells. From Table/Range would turn it into a table anyway, so make the table yourself and choose its name.

Click a cell in the list, press Ctrl+T, keep My table has headers ticked and click OK. Excel calls it Table1, so type a name with no spaces in the Table Name box. Type a sale in the row below and the table grows to take it in.

Make it a table first. Then the list can grow.

The editor

How Excel Records Your Steps

Every change becomes a named step, run in order.

Let's say you rename a column. Excel records a step called Renamed Columns and adds it to Applied Steps. All the steps together are the query: a new version of the data, while the original stays unchanged.

Click a step and the preview shows the data as it was then. Made a mistake? Right-click the step and choose Delete.

A query is a recipe, not an edit.

Loading the Result to a Sheet

Close & Load puts the finished query on a new sheet.

Let's say your steps are done and the result is still in the editor. Choose Home, then Close & Load. A single query loads to a new worksheet, and your original sheet stays where it was.

Click a cell in the result and a Query tab appears: Power Query put it there. Query, then Edit, reopens it. Name the sheet tabs, say DataTable and QueryTable, so you don't mix them up.

One sheet you type into. One sheet Power Query fills.

Importing a CSV or Text File

A CSV is plain text, and Power Query splits it into columns.

Let's say your system exports a CSV: plain text, with a comma between each value. Choose Data, Get Data, From File, From Text/CSV, and open it.

Kinds of data

Setting the Kind of Data Early

Number, text or date. Check Power Query's guess.

Let's say your dates won't filter by month. Their kind of data is wrong. Every column has one, shown by an icon on the left of its heading.

Power Query guesses each kind from the first 200 rows and records it as two steps, Promoted Headers and Changed Type. A wrong guess can cause errors on refresh, and date options stay greyed out until a column is a date.

Check the headings before anything else.

Dates That Arrive as Text

Day first or month first? Tell Power Query which.

Let's say your export writes the day first, like the 22nd of January. Power Query reads dates using your computer's regional setting. Read month first, there's no month 22, and you get an error.

Right-click the heading, choose Change Type, Using Locale, and pick Date and a region that writes the day first. The dates come in right. Data, Get Data, Query Options sets it for the whole workbook.

Tell Power Query how the dates were written.

Numbers That Arrive as Text

A number stored as text won't add up.

Let's say the Amount column looks fine but won't add up. The values are numbers stored as text, which Power Query's Text kind allows.

Change the column to a number kind with Home, Data Type. A value that can't convert, like NA, shows as Error; the query still loads, and clicking beside Error shows why. Every other value becomes a number that adds up.

Text that looks like a number still isn't one.

Not every query needs its own sheet.

Let's say you've made a few queries, and only the last one is the answer. Loading every one fills the workbook with sheets you never look at.

Choose Close & Load To and pick Only Create Connection. The query stays, with no sheet, and can still feed others: Microsoft's own example loads only the combined result. Change it later with Load To in Queries & Connections.

Load the answer. Connect the rest.
