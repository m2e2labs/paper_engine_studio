# Glossary

The author's list of terms. A glossary page prints the terms the pages actually use,
with the meaning given here. Add a term or change a meaning only with the author.

## Power Query
- **Means:** the part of Excel that brings data in and cleans it, recording each step so it can repeat them.
- **Also:** Get & Transform

## Query
- **Means:** a saved set of steps that reads data from a source and shapes it.
- **Also:** queries

## Step
- **Means:** one recorded action in a query, such as removing a column.
- **Also:** steps

## Applied Steps
- **Means:** the list of a query's steps, in order, on the right of the editor.

## Power Query Editor
- **Means:** the window where you build and change a query.

## Append
- **Means:** putting one table's rows under another's, with columns matched by heading.
- **Also:** appending, appended

## Merge
- **Means:** joining two tables side by side on a column they share.
- **Also:** merging, merged

## Unpivot
- **Means:** turning columns across the top, such as months, into rows.
- **Also:** unpivoting, unpivoted

## Refresh
- **Means:** running a query's steps again on the data in its source now.
- **Also:** refreshes, refreshing

## Data Model
- **Means:** tables kept inside the workbook for PivotTables to use.
