# Glossary

The author's list of terms. A glossary page prints the terms the pages actually use,
with the meaning given here. Add a term or change a meaning only with the author.

## Workbook
- **Means:** the Excel file itself. It holds one or more sheets.

## Sheet
- **Means:** one page of cells inside a workbook. The tabs along the bottom switch between sheets.

## Cell
- **Means:** one box on a sheet. Its address is its column letter and row number, such as B2.

## Formula
- **Means:** something you type into a cell that starts with an equals sign and tells Excel what to work out.

## Function
- **Means:** a ready-made formula that Excel already knows, such as SUM, which adds up numbers.

## Group of cells
- **Means:** several cells next to each other, written as the first and last cell, such as A1:A10.

## Table
- **Means:** a block of rows and columns that Excel formats and manages as one unit, with filter buttons on its heading row.

## Filter
- **Means:** hide every row except the ones that match what you choose. Nothing is deleted.

## Sort
- **Means:** put rows in order, such as A to Z or from the biggest number to the smallest.

## Summary table
- **Means:** a table that adds up your rows by group, for example the total sales for each region. Excel calls this a PivotTable.

## Chart
- **Means:** a picture of your numbers, such as a column for each region.
